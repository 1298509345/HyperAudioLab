# 两台 Android 手机传音频（0.7）

本页针对 Android0.7 同一APK的发送/接收两种角色。iPhone接收端仍用0.6.5；实际安装包、验证范围和签名请看releases/RELEASES.md。

1. 两台手机安装同一份Android0.7 APK，连接同一Wi-Fi或个人热点。若热点设备间隔离导致发现失败，可使用接收页给出的手动地址。
2. 手机B连接蓝牙、有线或USB耳机，在首页选择“接收”，点开始接收。没有耳机时默认静音等待；确需外放，主动切换到手机扬声器。每次新接收会话重新默认为耳机。
3. 手机A在首页选择“发送”，一键连接手机B；首次在B确认允许。随后在A允许系统音频采集授权，跨App播放请在系统提供该选项时选择共享整个屏幕。
4. 在A播放系统允许采集的音视频，声音经局域网送到B；B不需要屏幕共享或录音授权。受保护音源、系统撤权、厂商后台限制仍可能影响使用。
5. B可暂停/恢复播放，暂停保留接收会话；恢复播放新音频，不回放暂停期间积压。完整停止可在App或系统快捷入口操作。
6. 角色切换前先结束当前会话，同一手机不同时收发；避免把收到的声音又送回另一台。已配对设备可在设备页管理。

## 需要分清的状态

收到音频包说明网络到达；播放轨道推进说明系统AudioTrack消费数据；这两项都不能独立证明耳机实际有声。请同时核对B的输出设备、媒体音量和实际听感。耳机断开、来电或其他App占用音频时应暂停/让路；手动暂停不会自动恢复。

## 隐私

Android接收只在内存中缓冲，不保存收到的音频。发送端仍保留明确开启后才保存前五分钟PCM的可选功能。初次配对和音频没有端到端加密，请在可信网络使用。Android0.7说明原文见“隐私说明-Android-0.7.txt”；iOS0.6.5说明保留原版本。

## 验收范围

本机协议、缓冲和生命周期测试，以及模拟器实际网络/AudioTrack结果会记录在validation/。真实两台安卓的耳机听感、HyperOS锁屏长期保活及CPU/内存/耗电，需要真机另行核验，不能由模拟器结果代替。
