# HyperAudio 0.6 使用说明

本版采用已确认的 A 方案：“连接／设备／设置”。两端现有音频协议、快捷开关、后台恢复、睡眠定时和 0.5 音质设置保留。

## 安装包

- `HyperAudioLab-0.6.apk`：Android 优化构建，推荐日常试用；包名和本机旧版证书保持一致，可覆盖本机生成的 0.3–0.5，保留配对和设置。
- `HyperAudioLab-0.6-debug.apk`：保留调试构建，便于排错。
- `HyperAudioReceiver-0.6-signed.ipa`：iOS Release 开发签名，包含主 App、系统控件和原图标，仅适用于已登记 iPhone。主 App 签名有效至 **2026-11-13 13:02:15（北京时间）**，控件至同日 15:00:20，之后需重新签名安装。

Android 优化包沿用本机测试签名，不是商店生产签名；原 Windows 0.2 证书不同，仍需先备份数据再处理更新。iOS IPA 需通过 Xcode/设备安装工具安装，直接发送到手机不能自动完成安装。

本轮按用户要求先开发和本机验证，**没有更新真实手机**。0.5 的实际播放反馈不能替代 0.6 新版真机验收。旧安装包保留。

## 日常连接

1. 两台手机连同一 Wi-Fi 或热点，蓝牙耳机连接 iPhone 并选为系统媒体输出。
2. iPhone 在“连接”页点开始接收；Android 点连接并开始。
3. 首次在 iPhone 允许配对，再确认 Android 系统采集授权。跨 App 音视频使用请选择“整个屏幕”；本应用只采集允许的媒体音频，不创建视频流、不读取麦克风。
4. 播放后可切换 App 或锁屏。“暂停”保留会话及本次 Android 采集授权；“停止”结束本机任务，新建采集仍需系统授权。

首页只显示声音去向、状态和常用操作。收到包/非零电平与软件正在播放都不能证明人耳实际有声；遇到问题先查看实际系统音量和输出，再打开一键自检。

## 三页各做什么

| 页面 | 内容 |
|---|---|
| 连接 | 开始、暂停/恢复、停止、真实状态、音量/静音摘要、声道/模式和定时入口 |
| 设备 | 已配对设备、别名、最近连接、逐台解除配对；手动地址和配对码作为默认收起或二级备选；iPhone 可选择系统音频输出 |
| 设置 | 声音偏好、睡眠定时、后台/快捷开关指引、引导、自检详情、脱敏报告，以及原有实验工具 |

别名只在本机显示，不改变设备身份。旧版没有名称的配对会显示缩短的本地标识，认证连接后补齐名称。当前正在使用的设备需要先停止再解除配对；解除本地配对不会远程删除对方记录。

Android 的立即媒体静音、三种静音保护、测试音源和 PCM 存档在高级工具中保留。停止后音量不会自动恢复，请先暂停音源再自行调整。PCM 仍只保存前五分钟，超过额度继续转发。详细音频参数参见 [0.5 说明](QUICKSTART-v0.5.md)。

## 蓝牙耳机

iOS 不按耳机品牌设白名单，支持系统提供的蓝牙媒体输出（A2DP/可用 Bluetooth LE 路由）。App 显示实际系统输出名；耳机断开时暂停，恢复仍遵循用户暂停、本机音频优先和系统中断规则。仅支持通话的 HFP 路由不属于本媒体播放模式，不会为此开启麦克风。

AirPods 之外的品牌仍需实际设备验证，不能将“系统路由类型允许”当成所有型号均通过。无蓝牙的模拟器只验证提示和保护，不证明耳机可播放。

## 自检与报告

自检详情说明当前阻断项，提供输出选择、重试或重新授权等操作；详细包数、排队、路由和本地状态在详情中查看。iPhone 网络等待时可重试网络监听，不重设当前增益或睡眠 deadline。

诊断报告仅在你点击后生成并由系统保存/分享，不自动上传。默认不包含配对码、密钥、IP/SSID、完整设备 ID、设备名称/别名、文件路径和原始音频；本机查看的详细信息不等于对外报告。Android 保存使用系统文件选择器，iOS 生成后打开系统分享面板。

## 性能变化与验证边界

- iOS 音频缓冲按固定上限复用，减少逐包分配；旧会话回调、格式切换和重复归还受到隔离。状态只在变化时发布，当前输出由路由通知更新。
- Android 指标日志移到独立写入线程，队列条数和字节均有限，批量刷新；慢磁盘/日志写入失败不应卡住音频采集。页面不需要时不拼接长统计文本。原音量保护频率、音频缓冲上限与 PCM 额度保持。
- 本机微基准只证明特定代码路径的分配/等待减少；实际手机 CPU、内存稳定性、六十分钟锁屏耗电，以及不同品牌耳机和双机中断恢复留待下一轮真机测量，见 [VALIDATION.md](../../validation/VALIDATION.md)。
