# HyperAudio 0.5 音频体验版

安装 `HyperAudioLab-0.5-debug.apk` 和 `HyperAudioReceiver-0.5-signed.ipa`。安卓与本机生成的0.3/0.4证书一致，可以覆盖；原Windows0.2证书不同，需先导出数据再卸载安装。iOS仍为已登记iPhone的开发测试签名，具体有效期见 `validation/ios-0.5-ipa.json`。

基本连接、后台设置和快捷开关沿用 [0.4 使用说明](QUICKSTART-v0.4.md)。2026-11-07 已将 iOS 0.5 安装到已登记的 iPhone，并核对版本、成功启动；Android 0.5 与真实音频验收待继续。旧安装包保留。

## 立体声

安卓默认优先立体声，可关闭选择单声道。自动连接会确认iPhone支持，再初始化双声道采集；收端不支持或硬件初始化失败时会明确回退单声道。手动配对码连接缺少协商，保守使用单声道。

两端0.5支持48kHz双声道；iPhone收到数据后显示实际声道。立体声流量约1.57Mbps应用数据，单声道约0.79Mbps，不含网络额外开销；没有引入压缩编码。立体声不是源音频质量的保证，左右听感需实际音源验证。

PCM仍只保存前五分钟音频，单声道约28.8MB、立体声约57.6MB。到上限只结束存档，转发继续。

导出的立体声PCM可用 `python tools/pcm_tool.py wav stereo.pcm stereo.wav --channels 2` 转成双声道WAV；单声道省略该参数即可。

## iPhone 播放设置

- **低延迟**：启动缓冲20ms、软件排队20ms，积压上限120ms，偏向看视频。
- **稳定**：启动缓冲80ms、软件排队60ms，积压上限300ms，默认选项，偏向连续音频。
- 设置会记住；切换模式会清旧缓冲后重新缓冲。以上是软件策略目标，不含Wi-Fi调度、音频引擎和AirPods蓝牙延迟，不代表端到端实测值。
- **接收音量**是App内0–100%增益，默认50%，会记住；起播/恢复约0.35秒渐入，调节时短渐变。系统媒体音量仍需自行调整，App不会替你修改它。
- **iPhone本机音频优先**默认开启。本机音频或通话发生中断/静音提示时让路；会话有效、蓝牙正常且系统允许恢复后尝试恢复。不同App可能不给完整恢复通知，此时点“恢复声音”。用户手动暂停/停止不会被自动恢复覆盖。

自检也会检查App接收增益是否为零。后台可收到哪些通知由系统决定，不能保证所有App间完全自动切换。参考 [Apple 音频提示说明](https://developer.apple.com/documentation/avfaudio/avaudiosession/silencesecondaryaudiohintnotification)。

## 睡眠定时

两端各有关闭、15、30、60、120分钟选项，默认关闭。iPhone选择后作用当前接收会话（未运行时作用下次开始），并显示剩余时间。安卓选择后可更新或取消当前采集会话。

定时使用单调时间，绑定当前会话；到期只停止本端转发/接收，不替你暂停第三方音源，也不恢复安卓媒体音量。要让两端都结束，请分别设置。旧会话的到期事件不会停止新会话。

## 日志与节能

安卓指标每段最多约1MiB、每会话最多三段；后台清理超过七天或历史指标合计超过20MiB的自身metrics文件，保护当前会话。PCM和无关文件不会自动删除。需要长期保留的CSV请导出。

安卓复用音频包缓冲，统计/通知/界面更新限频；250ms媒体音量保护保留。iPhone空闲/暂停时降低接收泵唤醒频率，有音频包后恢复。尚未实测省电幅度，不保证系统永不结束后台会话。

新增蓝紫色音频波形图标，已加入AppIcon资源并在模拟器主屏幕观察。使用内置imagegen生成，图标资源位于 `ios/HyperAudioReceiver/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`，生成提示词和来源记录在 `validation/ios-0.5-icon.json`。

## 真机验收

1. 两端更新后连接，验证立体声左右测试音，切换单声道并确认实际状态。
2. 对比低延迟/稳定模式的口型和卡顿，调节接收音量、暂停恢复，确认没有突变。
3. iPhone播放本地视频/接电话后，观察让路和允许恢复；缺少通知时验证一键恢复。
4. 验证两端睡眠定时、手动取消、停止后重开，确认旧定时不误停。
5. 双机锁屏持续播放、网络切换、耳机断连及耗电仍需实际设备验收。
